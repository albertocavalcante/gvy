## Requirements

- Java 17 or newer
- Groovy 4.0+

## Build

```bash
./gradlew build
```

This produces a fat JAR under `build/libs/`.

## Run

### Stdio mode (default)

```bash
java -jar build/libs/groovy-lsp-<version>.jar
```

### Socket mode

```bash
java -jar build/libs/groovy-lsp-<version>.jar socket 8080
```

Socket mode listens on the loopback interface only. To bind another address (for example inside a container), pass `--host <address>` to the `lsp` command; this exposes the server to the network, so only do it on trusted networks.
