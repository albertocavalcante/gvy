## Requirements

- Java 17 or newer
- Groovy 4.0+

## Build

```bash
./gradlew build
```

This produces a fat JAR under `build/libs/`.

## Run

### Stdio mode (default)

```bash
java -jar build/libs/groovy-lsp-<version>.jar
```

### Socket mode

```bash
java -jar build/libs/groovy-lsp-<version>.jar socket 8080
```

Socket mode listens on the IPv4 loopback address (`127.0.0.1`) only. To bind another address, such as `0.0.0.0` inside a container or `::1` for IPv6 loopback, use `lsp socket --host <address>`. Non-loopback addresses expose the unauthenticated server to the network, so only use them on trusted networks.
