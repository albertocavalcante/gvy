# Groovy language tools

Edit Groovy with the gvy language server and VS Code extension.

The stable v0.5.4 extension bundles an older 0.4.8 server. Read the [release limitation](https://github.com/albertocavalcante/gvy/blob/main/docs/installation.md#stable-release-limitation) before evaluating server fixes.

Start with the [quickstart](/gvy/guides/quickstart/) or browse the [settings reference](/gvy/reference/settings/).
