# Oracle advisory scope

These historical binaries are development test inputs. The language server consumes offline metadata; it does not boot
this controller or execute these plugins. A successful oracle result proves the pinned parser/validator controls and
runtime checks, not CPS, Pipeline execution, sandbox approval, DAP/debugger behavior, or production safety.

The advisory inventory uses update-center snapshot `b131aec6ec77e8191c345655d6d45eb1c4742278c7d8fdea529e25e368adccd1`
and release metadata snapshot `718172e12c747912913b10eaea389a336d85431fa6656b0c498646e765eac97d`, retrieved on
2026-11-15. Warning regular expressions are matched against the **whole version string**, as Jenkins does. A
warning-group match is not proof that every issue on its advisory page affects the target.

The current core 2.580.2 and its 56-plugin graph have no warning matches in that snapshot. This is a dated inventory,
not a promise that the binaries have no vulnerabilities. The legacy core 2.479.3 matches ten core advisory groups; its
plugin exceptions below cannot be cleared using the advertised compatible releases in the snapshot.

## Bounded legacy exception

- **Owner:** maintainers of `tools/jenkins-extractor/oracle`.
- **Scope:** the exact checked-in legacy lock, non-root isolated homes, trusted maintained fixtures, no listeners, no
  login accounts, no jobs/agents/executors, one bounded JVM, and mandatory pre/post security and OS socket checks.
- **Review expiry:** 2027-02-12, or any change to the target, graph, harness, fixture trust or relevant advisory,
  whichever comes first. Refresh this inventory and review the exception before further use after expiry.
- **Removal gate:** retire the historical binary oracle when the compatibility target is retired, or replace its
  evidence with a fixed environment while clearly ceasing to claim exact 2.479.3 validation.
- **Limits:** this is not an OS sandbox or continuous network monitor. Plugin initialization executes trusted binary
  code as the local user. Unknown vulnerabilities and interactions remain possible. No user workspace/plugin code,
  untrusted Jenkinsfile, shared library, credentials or user controller belongs in this harness.

Compatible fixed overrides remove avoidable script-security, credentials-binding and Jakarta Mail advisories. In
particular, Jakarta Mail API 2.1.5-1 (required core 2.479.1) replaces vulnerable 2.1.3-1; the
[SMTP injection advisory](https://www.jenkins.io/security/advisory/2025-09-03/#SECURITY-3617) identifies the first fix
as 2.1.3-3. The remaining exact plugin exceptions are:
