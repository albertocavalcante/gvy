⏺ This is a fantastic question. Let me analyze what we learned and design a proper tool architecture.

  Feasibility Analysis

  Based on this migration, here's my honest assessment:

  | Category           | Automation Accuracy | Approach                        |
  |--------------------|---------------------|---------------------------------|
  | Module discovery   | 95%+                | Parse settings.gradle.kts       |
  | Version catalog    | 99%                 | Parse libs.versions.toml (TOML) |
  | Basic dependencies | 85-90%              | Gradle Tooling API              |
  | Test configuration | 80%                 | Heuristics + Tooling API        |
  | Custom plugins     | 30-50%              | Pattern matching only           |
  | Code generation    | 40-60%              | Task analysis                   |
  | TypeScript/NPM     | 90%                 | Parse package.json              |

  Overall: ~75-85% automation for standard projects

  The Core Problem

  Gradle build scripts are Turing-complete Kotlin programs, not configuration files:

  // This is trivial to parse
  dependencies {
      implementation("org.apache.groovy:groovy:4.0.29")
  }

  // This requires execution to understand
  dependencies {
      if (project.hasProperty("useNewApi")) {
          implementation(libs.newApi)
      } else {
          implementation(libs.legacyApi)
      }
  }

  // This is impossible without running the plugin
  plugins {
      id("com.company.magic-plugin")  // What does this add?
  }

  Two Fundamental Approaches

  Approach A: Static Analysis (AST-based)

  ┌─────────────────────────────────────────────────────────────┐
  │                    Static Analysis                          │
  ├─────────────────────────────────────────────────────────────┤
  │  build.gradle.kts  ──▶  Kotlin AST  ──▶  Extract Patterns  │
  │                              │                              │
  │                              ▼                              │
  │                    Pattern Matching:                        │
  │                    - dependencies { }                       │
  │                    - plugins { }                            │
  │                    - tasks.register { }                     │
  └─────────────────────────────────────────────────────────────┘

  Pros:
  ✓ Fast (no Gradle execution)
  ✓ Works offline
  ✓ Predictable behavior

  Cons:
  ✗ Can't resolve version.ref to actual versions
  ✗ Can't see plugin effects
  ✗ Can't handle dynamic logic
  ✗ Misses transitive dependencies

  Approach B: Gradle Tooling API (Runtime)

  ┌─────────────────────────────────────────────────────────────┐
  │                  Gradle Tooling API                         │
  ├─────────────────────────────────────────────────────────────┤
  │  GradleConnector  ──▶  ProjectConnection  ──▶  Models      │
  │                              │                              │
  │                              ▼                              │
  │                    Query actual state:                      │
  │                    - Resolved dependencies                  │
  │                    - Source sets                            │
  │                    - Task graph                             │
  │                    - Plugin contributions                   │
  └─────────────────────────────────────────────────────────────┘

  Pros:
  ✓ Sees REAL resolved state
  ✓ Handles plugins correctly
  ✓ Gets transitive dependencies
  ✓ Resolves version catalogs

  Cons:
  ✗ Requires valid Gradle project
  ✗ Slower (executes Gradle)
  ✗ May trigger side effects

  Recommended: Hybrid Architecture

  ┌──────────────────────────────────────────────────────────────────────────┐
  │                        GRADLE-TO-BAZEL MIGRATOR                          │
  ├──────────────────────────────────────────────────────────────────────────┤
  │                                                                          │
  │  ┌────────────────────────────────────────────────────────────────────┐  │
  │  │ Layer 1: DATA EXTRACTION                                           │  │
  │  ├────────────────────────────────────────────────────────────────────┤  │
  │  │                                                                    │  │
  │  │  ┌─────────────┐   ┌─────────────┐   ┌─────────────────────────┐  │  │
  │  │  │ TOML Parser │   │ Kotlin AST  │   │ Gradle Tooling API      │  │  │
  │  │  │             │   │ Parser      │   │                         │  │  │
  │  │  │ libs.       │   │ settings.   │   │ - IdeaProject model     │  │  │
  │  │  │ versions.   │   │ gradle.kts  │   │ - DependencyGraph       │  │  │
  │  │  │ toml        │   │             │   │ - SourceSets            │  │  │
  │  │  └──────┬──────┘   └──────┬──────┘   └───────────┬─────────────┘  │  │
  │  │         │                 │                      │                │  │
  │  └─────────┼─────────────────┼──────────────────────┼────────────────┘  │
  │            │                 │                      │                    │
  │            ▼                 ▼                      ▼                    │
  │  ┌────────────────────────────────────────────────────────────────────┐  │
  │  │ Layer 2: INTERMEDIATE REPRESENTATION (IR)                          │  │
  │  ├────────────────────────────────────────────────────────────────────┤  │
  │  │                                                                    │  │
  │  │   ProjectGraph {                                                   │  │
  │  │     modules: Map<ModulePath, ModuleInfo>                          │  │

  // Known plugin -> Bazel rule mapping
  val PLUGIN_MAPPINGS = mapOf(
      "org.jetbrains.kotlin.jvm" to RuleMapping(
          rule = "@rules_kotlin//kotlin:jvm.bzl",
          targetType = "kt_jvm_library"
      ),
      "application" to RuleMapping(
          rule = "@rules_kotlin//kotlin:jvm.bzl",
          targetType = "kt_jvm_binary"
      ),
      "com.squareup.wire" to RuleMapping(
          rule = "//tools/build_defs:wire.bzl",
          targetType = "wire_library",
          requiresManualReview = true
      ),
      // Unknown plugins -> flag for manual review
  )

  fun detectPluginEffects(module: GradleModule): PluginAnalysis {
      val known = module.plugins.filter { it.id in PLUGIN_MAPPINGS }
      val unknown = module.plugins.filter { it.id !in PLUGIN_MAPPINGS }

      return PluginAnalysis(
          mappedPlugins = known.map { PLUGIN_MAPPINGS[it.id]!! },
          unknownPlugins = unknown,
          requiresManualReview = unknown.isNotEmpty()
      )
  }

  fun detectCodeGeneration(module: GradleModule): List<CodeGenTask> {
      return module.tasks.filter { task ->
          // Heuristics for code generation

          task.outputs.any { it.path.contains("generated") } ||
          task.type in CODE_GEN_TASK_TYPES

  // universal_build.proto - The core schema

  syntax = "proto3";
  package unibazel;

  // Root project representation
  message Project {
    string name = 1;
    string version = 2;
    string root_path = 3;
    SourceEcosystem source_ecosystem = 4;

    repeated Module modules = 10;
    repeated ExternalDependency external_deps = 11;
    DependencyGraph dep_graph = 12;

    // Ecosystem-specific metadata (extensible)
    google.protobuf.Any ecosystem_metadata = 20;
  }

  enum SourceEcosystem {
    UNKNOWN = 0;
    GRADLE_KOTLIN = 1;
    GRADLE_GROOVY = 2;
    MAVEN = 3;
    SBT = 4;
    CARGO = 5;
    POETRY = 6;
    PDM = 7;
    NPM = 8;
    PNPM = 9;
    YARN = 10;
    GO_MOD = 11;
    BAZEL = 12;  // For Bazel-to-Bazel migrations/upgrades
  }

  message Module {
    string name = 1;
    string path = 2;                    // Relative path from root
    ModuleType type = 3;

    repeated SourceSet source_sets = 10;
    repeated Dependency dependencies = 11;
    repeated BuildTarget targets = 12;

    // What plugins/features are enabled
    repeated PluginUsage plugins = 20;

    // Ecosystem-specific (Cargo features, Gradle plugins, etc.)
    google.protobuf.Any ecosystem_specific = 30;
  }

  enum ModuleType {
    LIBRARY = 0;
    BINARY = 1;
    TEST = 2;
    BUILD_PLUGIN = 3;      // Gradle buildSrc, Cargo build.rs
    VIRTUAL = 4;           // Workspace root, no outputs
  }

  message SourceSet {
    string name = 1;                    // main, test, integ_test, bench
    repeated string languages = 2;      // kotlin, java, rust, python, ts
    repeated string source_dirs = 3;
    repeated string resource_dirs = 4;
    repeated string generated_dirs = 5;
  }

  message Dependency {
    oneof dep {
      InternalDep internal = 1;
      ExternalDep external = 2;
    }
    DependencyScope scope = 3;
    bool optional = 4;

  enum DependencyScope {
    COMPILE = 0;
    RUNTIME = 1;
    TEST = 2;
    DEV = 3;

    string module_path = 1;             // ":core" or "crates/core"

  message ExternalDep {
    string registry = 1;                // maven_central, crates_io, pypi, npm
    string group = 2;                   // org.apache.groovy, @types

    Type type = 1;
    string min_version = 2;
    string max_version = 3;
  }

  message BuildTarget {
    string name = 1;
    TargetType type = 2;
    string entry_point = 3;             // main class, main.rs, index.ts
    repeated string source_globs = 4;
    map<string, string> build_config = 5;
  }

  enum TargetType {
    LIB = 0;
    BIN = 1;
    TEST = 2;
    BENCH = 3;
    EXAMPLE = 4;
  }

  message PluginUsage {

    map<string, string> configuration = 3;

  message PluginEffect {

    repeated string adds_dependencies = 2;

  class GradleExtractor {
      fun extract(projectDir: Path): UIR.Project {
          val connection = GradleConnector.newConnector()
              .forProjectDirectory(projectDir.toFile())
              .connect()

          return connection.use { conn ->
              val ideaProject = conn.getModel(IdeaProject::class.java)
              val dependencyGraph = conn.getModel(DependencyGraph::class.java)

              UIR.Project.newBuilder()
                  .setName(ideaProject.name)
                  .setSourceEcosystem(SourceEcosystem.GRADLE_KOTLIN)
                  .addAllModules(ideaProject.modules.map { it.toUIRModule() })
                  .setDepGraph(dependencyGraph.toUIR())
                  .build()
          }
      }
  }

  // Entry point for subprocess invocation
  fun main(args: Array<String>) {
      val projectDir = Path.of(args[0])
      val output = Path.of(args[1])

      val uir = GradleExtractor().extract(projectDir)
      output.writeBytes(uir.toByteArray())
  }

  // cargo-extractor/src/main.rs
  // Native Rust binary

  use cargo_metadata::{MetadataCommand, Package, Dependency};
  use unibazel_proto::*;

  fn extract(manifest_path: &Path) -> Project {
      let metadata = MetadataCommand::new()
          .manifest_path(manifest_path)
          .exec()
          .expect("Failed to get cargo metadata");

      let mut project = Project::default();
      project.name = metadata.workspace_root.file_name().unwrap().to_string();
      project.source_ecosystem = SourceEcosystem::Cargo as i32;

      for package in &metadata.packages {
          project.modules.push(package_to_module(package, &metadata));
      }

      project.dep_graph = Some(build_dep_graph(&metadata));
      project
  }

  fn package_to_module(pkg: &Package, metadata: &Metadata) -> Module {
      let mut module = Module::default();
      module.name = pkg.name.clone();
      module.path = pkg.manifest_path.parent().unwrap()
          .strip_prefix(&metadata.workspace_root)
          .unwrap_or(Path::new(""))
          .to_string();

      // Detect targets
      for target in &pkg.targets {
          module.targets.push(cargo_target_to_uir(target));
      }

      // Dependencies
      for dep in &pkg.dependencies {
          module.dependencies.push(cargo_dep_to_uir(dep));
      }

      module
  }

  fn main() {
      let args: Vec<String> = std::env::args().collect();
      let manifest_path = Path::new(&args[1]);
      let output_path = Path::new(&args[2]);

      let project = extract(manifest_path);

      let bytes = project.encode_to_vec();
      std::fs::write(output_path, bytes).unwrap();
  }

  import sys
  import tomllib
  from pathlib import Path
  from unibazel_proto import Project, Module, Dependency, SourceEcosystem

  def extract(project_dir: Path) -> Project:
      pyproject = project_dir / "pyproject.toml"
      poetry_lock = project_dir / "poetry.lock"

      with open(pyproject, "rb") as f:
          config = tomllib.load(f)

      poetry_config = config.get("tool", {}).get("poetry", {})

      project = Project()
      project.name = poetry_config.get("name", project_dir.name)
      project.source_ecosystem = SourceEcosystem.POETRY

      # Main module
      module = Module()
      module.name = project.name
      module.path = "."

      # Source sets
      src_dir = project_dir / "src" / project.name
      if src_dir.exists():
          module.source_sets.append(make_source_set("main", [str(src_dir)]))

      tests_dir = project_dir / "tests"
      if tests_dir.exists():
          module.source_sets.append(make_source_set("test", [str(tests_dir)]))

      # Dependencies
      for name, spec in poetry_config.get("dependencies", {}).items():
          if name == "python":
              continue
          module.dependencies.append(poetry_dep_to_uir(name, spec, "compile"))

      for name, spec in poetry_config.get("group", {}).get("dev", {}).get("dependencies", {}).items():
          module.dependencies.append(poetry_dep_to_uir(name, spec, "dev"))

      project.modules.append(module)

      # Parse lock file for resolved versions
      if poetry_lock.exists():
          project.dep_graph = parse_poetry_lock(poetry_lock)

      return project

  if __name__ == "__main__":
      project_dir = Path(sys.argv[1])
      output_path = Path(sys.argv[2])

      project = extract(project_dir)
      output_path.write_bytes(project.SerializeToString())

  pnpm Extractor (TypeScript)

  // pnpm-extractor/src/index.ts

  import { readFileSync, writeFileSync } from 'fs';
  import { parse as parseYaml } from 'yaml';
  import { Project, Module, SourceEcosystem } from './unibazel_proto';

  interface PackageJson {
    name: string;
    version: string;
    dependencies?: Record<string, string>;
    devDependencies?: Record<string, string>;
    workspaces?: string[];
  }

  function extract(projectDir: string): Project {
    const packageJsonPath = `${projectDir}/package.json`;
    const pnpmLockPath = `${projectDir}/pnpm-lock.yaml`;
    const pnpmWorkspacePath = `${projectDir}/pnpm-workspace.yaml`;

    const packageJson: PackageJson = JSON.parse(readFileSync(packageJsonPath, 'utf-8'));

    const project = Project.create({
      name: packageJson.name,
      sourceEcosystem: SourceEcosystem.PNPM,
    });

    // Check for workspaces (monorepo)
    let workspacePackages: string[] = [];
    try {
      const workspaceConfig = parseYaml(readFileSync(pnpmWorkspacePath, 'utf-8'));
      workspacePackages = workspaceConfig.packages || [];
    } catch {
      // Not a workspace
    }

    if (workspacePackages.length > 0) {
      // Monorepo - extract each package
      for (const pattern of workspacePackages) {
        const packages = glob.sync(pattern, { cwd: projectDir });
        for (const pkg of packages) {
          project.modules.push(extractPackage(`${projectDir}/${pkg}`));
        }
      }
    } else {
      // Single package
      project.modules.push(extractPackage(projectDir));
    }

    // Parse lock file for dependency graph
    try {
      const lockfile = parseYaml(readFileSync(pnpmLockPath, 'utf-8'));
      project.depGraph = parsePnpmLock(lockfile);
    } catch {
      // No lock file
    }

    return project;
  }

  // CLI entry point
  const projectDir = process.argv[2];
  const outputPath = process.argv[3];

  const project = extract(projectDir);
  writeFileSync(outputPath, Project.encode(project).finish());

  // core/src/main.rs

  use std::path::Path;
  use std::process::Command;
  use unibazel_proto::*;

  mod extractors;
  mod transformers;
  mod generators;

  struct MigrationEngine {
      extractors: HashMap<SourceEcosystem, Box<dyn Extractor>>,
      generators: HashMap<TargetSystem, Box<dyn Generator>>,
  }

  impl MigrationEngine {
      fn new() -> Self {
          let mut engine = Self {
              extractors: HashMap::new(),
              generators: HashMap::new(),
          };

          // Register extractors (subprocess-based)
          engine.extractors.insert(
              SourceEcosystem::GradleKotlin,
              Box::new(SubprocessExtractor::new("gradle-extractor", &["java", "-jar"]))
          );
          engine.extractors.insert(
              SourceEcosystem::Cargo,
              Box::new(SubprocessExtractor::new("cargo-extractor", &[]))
          );
          engine.extractors.insert(
              SourceEcosystem::Poetry,
              Box::new(SubprocessExtractor::new("poetry-extractor", &["python"]))
          );
          engine.extractors.insert(
              SourceEcosystem::Pnpm,
              Box::new(SubprocessExtractor::new("pnpm-extractor", &["node"]))
          );

          // Register generators
          engine.generators.insert(
              TargetSystem::Bazel,
              Box::new(BazelGenerator::new())
          );

          engine
      }

      fn detect_ecosystem(&self, project_dir: &Path) -> Option<SourceEcosystem> {
          // Detection priority order
          let indicators = [
              ("Cargo.toml", SourceEcosystem::Cargo),
              ("pyproject.toml", SourceEcosystem::Poetry),  // Check for [tool.poetry]
              ("pnpm-lock.yaml", SourceEcosystem::Pnpm),
              ("yarn.lock", SourceEcosystem::Yarn),
              ("package-lock.json", SourceEcosystem::Npm),
              ("go.mod", SourceEcosystem::GoMod),
              ("build.gradle.kts", SourceEcosystem::GradleKotlin),
              ("build.gradle", SourceEcosystem::GradleGroovy),
              ("pom.xml", SourceEcosystem::Maven),
              ("build.sbt", SourceEcosystem::Sbt),
          ];

          for (file, ecosystem) in indicators {
              if project_dir.join(file).exists() {
                  return Some(ecosystem);
              }
          }

          None
      }

      fn migrate(
          &self,
          project_dir: &Path,
          target: TargetSystem,
          options: MigrationOptions,
      ) -> Result<MigrationResult, MigrationError> {
          // 1. Detect ecosystem
          let ecosystem = self.detect_ecosystem(project_dir)
              .ok_or(MigrationError::UnknownEcosystem)?;

          println!("Detected ecosystem: {:?}", ecosystem);

          // 2. Extract UIR
          let extractor = self.extractors.get(&ecosystem)
              .ok_or(MigrationError::UnsupportedEcosystem(ecosystem))?;

          let uir = extractor.extract(project_dir)?;

          // 3. Validate and enrich UIR
          let uir = self.validate_and_enrich(uir)?;

          // 4. Transform to target
          let generator = self.generators.get(&target)
              .ok_or(MigrationError::UnsupportedTarget(target))?;

          let output = generator.generate(&uir, &options)?;

          // 5. Write output
          self.write_output(project_dir, &output)?;

          // 6. Validate (optional)
          let validation = if options.validate {
              Some(self.validate_output(project_dir, target)?)
          } else {
              None
          };

          Ok(MigrationResult {
              uir,
              output,
              validation,
              report: self.generate_report(&uir, &output),
          })
      }
  }

  fn main() {
      let args = Args::parse();

      let engine = MigrationEngine::new();

      match engine.migrate(
          &args.project_dir,
          args.target.unwrap_or(TargetSystem::Bazel),
          args.into(),
      ) {
          Ok(result) => {
              println!("Migration complete!");
              println!("{}", result.report);
          }
          Err(e) => {
              eprintln!("Migration failed: {}", e);
              std::process::exit(1);
          }
      }
  }

  // core/src/generators/bazel.rs

  use unibazel_proto::*;
  use std::collections::HashMap;

  pub struct BazelGenerator {
      templates: TemplateEngine,
      rule_mappings: HashMap<(SourceEcosystem, ModuleType), RuleMapping>,
  }

  impl BazelGenerator {
      pub fn new() -> Self {
          let mut mappings = HashMap::new();

          // Gradle Kotlin -> Bazel
          mappings.insert(
              (SourceEcosystem::GradleKotlin, ModuleType::Library),
              RuleMapping {
                  load: "@rules_kotlin//kotlin:jvm.bzl",
                  rule: "kt_jvm_library",
                  dep_transform: Box::new(maven_to_bazel_label),
              }
          );

          // Cargo -> Bazel
          mappings.insert(
              (SourceEcosystem::Cargo, ModuleType::Library),
              RuleMapping {
                  load: "@rules_rust//rust:defs.bzl",
                  rule: "rust_library",
                  dep_transform: Box::new(crate_to_bazel_label),
              }
          );

          // Poetry -> Bazel
          mappings.insert(
              (SourceEcosystem::Poetry, ModuleType::Library),
              RuleMapping {
                  load: "@rules_python//python:defs.bzl",
                  rule: "py_library",
                  dep_transform: Box::new(pypi_to_bazel_label),
              }
          );

          // pnpm -> Bazel
          mappings.insert(
              (SourceEcosystem::Pnpm, ModuleType::Library),
              RuleMapping {
                  load: "@aspect_rules_ts//ts:defs.bzl",
                  rule: "ts_project",
                  dep_transform: Box::new(npm_to_bazel_label),
              }
          );

          Self {
              templates: TemplateEngine::new(),
              rule_mappings: mappings,
          }
      }

      fn generate_module_bazel(&self, project: &Project) -> String {
          let mut content = String::new();

          // Header
          content.push_str(&format!(r#"module(
      name = "{}",
      version = "{}",
  )
  "#, project.name, project.version));

          // Detect which rule sets are needed
          let ecosystems: HashSet<_> = project.modules.iter()
              .map(|m| m.source_ecosystem())
              .collect();

          for ecosystem in ecosystems {
              content.push_str(&self.generate_bazel_deps(ecosystem));
          }

          // External dependencies
          content.push_str(&self.generate_external_deps(project));

          content
      }

      fn generate_build_file(&self, module: &Module, project: &Project) -> String {
          let mapping = self.rule_mappings
              .get(&(project.source_ecosystem(), module.module_type()))
              .expect("No mapping for module type");

          let mut content = String::new();

          // Load statement
          content.push_str(&format!(
              "load(\"{}\", \"{}\")\n\n",
              mapping.load, mapping.rule
          ));

          // Main target
          content.push_str(&self.generate_target(module, mapping, false));

          // Test target
          if module.has_tests() {
              content.push_str(&self.generate_target(module, mapping, true));
          }

          content
      }
  }

  // Dependency label transformations
  fn maven_to_bazel_label(dep: &ExternalDep) -> String {
      // io.arrow-kt:arrow-core:2.2.1 -> @maven//:io_arrow_kt_arrow_core
      let label = format!("{}_{}", dep.group, dep.artifact)
          .replace('.', "_")
          .replace('-', "_")
          .replace(':', "_");
      format!("@maven//:{}", label)
  }

  fn crate_to_bazel_label(dep: &ExternalDep) -> String {
      // serde -> @crate_index//:serde
      format!("@crate_index//:{}", dep.artifact)
  }

  fn pypi_to_bazel_label(dep: &ExternalDep) -> String {
      // requests -> @pip//requests
      format!("@pip//{}", dep.artifact.replace('-', "_"))
  }

  fn npm_to_bazel_label(dep: &ExternalDep) -> String {
      // @types/node -> //:node_modules/@types/node
      if dep.group.is_empty() {
          format!("//:node_modules/{}", dep.artifact)
      } else {
          format!("//:node_modules/{}/{}", dep.group, dep.artifact)
      }
  }

  Accuracy Expectations by Ecosystem

  | Ecosystem     | Extraction Accuracy | Generation Accuracy | Notes                                 |
  |---------------|---------------------|---------------------|---------------------------------------|
  | Cargo         | 98%                 | 95%                 | Excellent metadata, rules_rust mature |
  | Poetry        | 95%                 | 90%                 | Good tooling, rules_python solid      |
  | pnpm          | 95%                 | 90%                 | Lock file is source of truth          |
  | Go mod        | 98%                 | 95%                 | Excellent metadata, Gazelle native    |
  | Gradle Kotlin | 85%                 | 80%                 | Tooling API good, but plugins opaque  |
  | Maven         | 90%                 | 85%                 | XML is deterministic, good resolution |
  | SBT           | 80%                 | 75%                 | Complex DSL, less tooling             |
  | Yarn/npm      | 90%                 | 85%                 | Good lock files                       |

  Why This Architecture Works

  1. Native Extractors = Maximum accuracy for each ecosystem
  2. Universal IR = Clean separation, ecosystem-agnostic transformations
  3. Rust Core = Fast, safe, excellent subprocess/WASM hosting
  4. Protobuf Schema = Language-agnostic, versionable, extensible
  5. Plugin Architecture = Add new ecosystems without touching core

  Final Recommendation

  Start with Cargo → Bazel as your first implementation:

  1. cargo metadata gives you EVERYTHING deterministically
  2. rules_rust is mature and well-documented
  3. No JVM complexity
  4. Validates your architecture before tackling harder ecosystems
